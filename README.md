# Análise de Campeões do League of Legends 🎮

Este projeto apresenta uma análise simples de dados de campeões do jogo **League of Legends**, usando **Python** com as bibliotecas `pandas` e `matplotlib`.

## 🔍 O que está incluído:

- `campeoes_lol.csv`: Base de dados com informações como função, dano e ano de lançamento dos campeões.
- `analise_lol.py`: Script que analisa os dados e gera gráficos.
- `grafico_dano.png`: Imagem gerada com gráfico de campeões por tipo de dano.

## 🧪 Análises realizadas:

- Quantidade de campeões por função primária;
- Tipos de dano principais mais comuns;
- Média de ano de lançamento por função;
- Gráfico de campeões por tipo de dano.

## ▶️ Como executar:

```bash
pip install pandas matplotlib
python analise_lol.py
